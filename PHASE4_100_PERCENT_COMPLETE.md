## 🎓 USAGE GUIDE

### Quick Start

```bash
# 1. Run migrations
php artisan migrate

# 2. Seed sample data
php artisan db:seed --class=App\Modules\HRM\Database\Seeders\LoanManagementSeeder
php artisan db:seed --class=App\Modules\HRM\Database\Seeders\AdvancedPayrollSeeder

# 3. Clear caches
php artisan route:clear && php artisan view:clear

# 4. Configure email (in .env)
MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
...

# Ready to use!
```

### Common Tasks

**Generate Monthly Payroll**
```
1. /hrm/payroll/create
2. Select month & year
3. Click "Start Generation"
4. Review → Download PDFs → Email
```

**Calculate Gratuity**
```
1. /hrm/gratuity/calculator
2. Select employee
3. Set calculation date
4. Preview calculation
5. Save & approve
```

**Generate Bank Transfer**
```
1. /hrm/bank-transfers
2. Select month/year
3. Choose format (NPSB/BEFTN/CSV)
4. Download file
5. Upload to bank portal
```
