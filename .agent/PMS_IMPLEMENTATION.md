## Features

### KPI/KRA Module
- List all KPIs/KRAs
- Create/Edit/Delete via offcanvas
- Assign to departments
- Set targets and weightage
- Track frequency

### OKR Module
- Company/Department/Individual OKRs
- Key Results tracking
- Progress visualization
- Quarterly planning

### Performance Goals
- Link to KPIs
- Priority management
- Progress tracking
- Note taking

### 360° Appraisal
- Self assessment
- Manager assessment
- Peer review
- Subordinate review
- Customer feedback (optional)
- Competency-based rating
- Overall score calculation

### PIP Module
- Create improvement plans
- Action items tracking
- Regular reviews
- Success/Failure outcomes
- Evidence documentation
