# 📘 Performance Management System (PMS) - User Guide

## 1. Overview
The Performance Management System (PMS) is a comprehensive suite designed to track, evaluate, and improve employee performance. It aligns individual goals with organizational objectives using modern frameworks like OKRs, KPIs, and 360° Feedback.

## 2. Key Modules & Features

### 🎯 KPIs & KRAs (Key Performance Indicators)
**Purpose:** Define quantifiable metrics for departments or specific roles.
- **KPI (Key Performance Indicator):** ongoing metrics (e.g., "Monthly Revenue").
- **KRA (Key Result Area):** broader areas of responsibility.
- **How to Use:**
  1. Go to **Performance > KPIs / KRAs**.
  2. Click **Add KPI**.
  3. Define the target value, unit (%, $), and frequency (Monthly/Quarterly).
  4. Assign to a **Department** (for team goals) or leave unassigned for general use.

### 🥇 Competencies
**Purpose:** Define behavioral skills and standards expected from employees.
- **Types:**
  - **Core:** Expected from everyone (e.g., Teamwork, Integrity).
  - **Functional:** Job-specific skills (e.g., Coding, Accounting).
  - **Leadership:** For managers (e.g., Strategic Thinking).
- **How to Use:**
  1. Go to **Performance > Competencies**.
  2. Create a library of competencies to be used in appraisals.

### 🚀 OKRs (Objectives and Key Results)
**Purpose:** Set ambitious, time-bound goals.
- **Objective:** The "What" (e.g., "Dominant Market Share").
- **Key Results:** The "How" (e.g., "Increase sales by 20%").
- **Levels:** Company-wide, Department-level, or Individual.
- **How to Use:**
  1. Go to **Performance > OKRs**.
  2. Create an **Objective** and define the timeframe (Quarter/Year).
  3. Add multiple **Key Results** with start and target values.
  4. **Update Progress:** As users achieve results, they update the current value, and the overall objective progress is calculated automatically.

### 🏆 Performance Goals
**Purpose:** Track individual employee objectives linked to their role.
- **Features:** Priority levels (High/Medium/Low), Due Dates, and Status tracking.
- **Linkage:** Goals can be linked to specific KPIs for measurable tracking.
- **How to Use:**
  1. Go to **Performance > Goals**.
  2. Managers or Employees create goals.
  3. Update status (Not Started -> In Progress -> Completed) and progress %.

### 🔄 360° Appraisals
**Purpose:** Holistic performance reviews collecting feedback from multiple sources.
- **Reviewers:**
  - **Self:** Employee reviews themselves.
  - **Manager:** Direct supervisor.
  - **Peer:** Colleagues at the same level.
  - **Subordinate:** Direct reports (for managers).
- **Process:**
  1. **Create Appraisal:** HR initiates an appraisal cycle (e.g., "Annual Review 2024").
  2. **Assign Reviewers:** Go to the Appraisal Details and add peers/managers.
  3. **Feedback:** Reviewers receive requests to rate competencies and provide comments.
  4. **Scoring:** System calculates an overall score based on all feedback.

### 📉 Performance Improvement Plans (PIP)
**Purpose:** Structured plan to help underperforming employees improve.
- **Workflow:**
  1. **Initiate:** Manager creates a PIP with a specific **Reason** and **Expected Goals**.
  2. **Action Items:** Define specific tasks/steps the employee must take.
  3. **Tracking:** Mark action items as completed/failed.
  4. **Conclusion:** Mark the PIP as **Successful** (employee improved) or **Unsuccessful**.

## 3. Standard Workflows

### 🗓️ Quarterly Review Cycle
1. **Start of Quarter:**
   - Leadership sets **Company OKRs**.
   - Departments set **Team OKRs** aligned with Company OKRs.
   - Employees create **Performance Goals** linked to these.
2. **Mid-Quarter:**
   - Employees update progress on Goals and OKR Key Results.
   - Managers review progress and provide informal feedback.
3. **End of Quarter:**
   - Initiate **360° Appraisal** for the period.
   - Close OKRs (mark as Completed).

### ⚠️ Handling Underperformance
1. Identification: Employee consistently misses **KPI Targets** or fails **Goals**.
2. **PIP Creation:** Manager creates a PIP with clear deadlines.
3. **Monitoring:** Weekly check-ins recorded in the system.
4. **Resolution:** If targets are met, PIP is closed as Successful.

## 4. User Roles & Permissions
- **Super Admin / HR Manager:** Full access to configure settings, create cycles, and view all data.
- **Manager:** Can view/edit goals and appraisals for their **direct reports**.
- **Employee:** Can view their own goals, update their own progress, and submit self-appraisals.
